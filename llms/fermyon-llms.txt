# Fermyon

> Fermyon Technologies builds Spin, the open-source developer framework and CLI for
> WebAssembly serverless applications, and operates two places to run Spin apps:
> Fermyon Cloud (cloud.fermyon.com) and Fermyon Wasm Functions, now shipping as
> Akamai Functions on Akamai Cloud. Spin and SpinKube are CNCF sandbox projects and
> their source now lives under the spinframework GitHub organization. Akamai acquired
> Fermyon; fermyon.com redirects to akamai.com/products/akamai-functions, while
> developer.fermyon.com, cloud.fermyon.com and the Fermyon GitHub org remain live.

## API contract

- [Fermyon Cloud REST API (OpenAPI 3.1, 40 paths / 61 operations)](https://raw.githubusercontent.com/fermyon/cloud-openapi/main/swagger.json): the first-party machine-readable contract, published in the fermyon/cloud-openapi repository. Base URL https://cloud.fermyon.com. Bearer JWT on every operation. Resources: accounts, apps, auth-tokens, channels, custom-domains, device-codes, key-value-pairs, key-value-stores, oci, payments, personal-access-tokens, revisions, sql-databases, variable-pairs.
- [REST API reference page](https://developer.fermyon.com/cloud/rest-api): points at the OpenAPI and the generated Rust client.
- Known gaps in the published contract: no `operationId` on any of the 61 operations, no `servers` block in the source document, and only `200` responses are declared — no 4xx/5xx shapes and no error schema.
